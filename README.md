# 🚀 My First C++ Program

A simple beginner-friendly C++ project created to learn the basics of C++ programming.

## ✨ Features

- Get user input
- Display personalized messages
- Basic C++ syntax
- Console output

## 🛠️ Requirements

- C++ Compiler (Clang or GCC)
- C++11 or newer

## 🚀 Compile and Run

Using Clang on macOS:

```bash
clang++ -std=c++20 -Wall -Wextra main.cpp -o main
./main
```
